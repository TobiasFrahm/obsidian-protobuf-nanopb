# Changelog

## 0.1.0 — 2026-11-05

Initial release of Protobuf & Nanopb Highlighting for Obsidian.

- Highlight `proto`, `protobuf`, and `nanopb` fenced code blocks.
- Highlight separate nanopb options using `nanopb-options`.
- Support Reading view, Live Preview, and Source mode.
- Use the active Obsidian theme's code colors.
- Provide a copy button in Reading view.

Requires Obsidian 1.8.7 or later.
